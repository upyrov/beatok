After making changes to the code, format it.
After making changes to the code, run `bun typecheck`.

Always use `bun` instead of `node`.
Always use `bun add` instead of `npm install`.
Always use `bun run` instead of `npm run`.
Always use `bunx` instead of `npx`.

If a function returns an object and does nothing else, make it a `const`.
If a function returns a single statement, make it an arrow function without a block.
